📦 Manual de Usuario — Gestión de Stocks

Versión del documento: 1.0  ·  Última revisión: agosto 2026

Bienvenido al manual de usuario

Este documento describe el funcionamiento completo del sistema de gestión de stocks. Cada sección corresponde a una página o funcionalidad de la aplicación. El contenido que ves depende de tu rol y de los permisos activados por el administrador.

👥 Roles del Sistema

La aplicación tiene tres niveles de acceso jerárquicos. Cada usuario tiene asignado uno de los siguientes roles:

usuario
  • Consulta de stocks
  • Propuestas (carrito)
  • Pedidos, albaranes, facturas
  • Consultas de producto
  • Favoritos y búsqueda mágica
  • Según permisos activados
administrador
  • Todo lo del rol usuario
  • Dashboard de estadísticas
  • Gestión de usuarios
  • Auditoría de accesos
  • Vista y informe de almacén
  • Propuestas y consultas globales
  • Configuración de email
superusuario
  • Todo lo del rol administrador
  • Parámetros del sistema
  • Control de base de datos
  • Acceso total sin restricciones

Permisos individuales por usuario

Además del rol base, el administrador puede activar o desactivar funcionalidades específicas para cada cuenta de usuario:

PROVer precios
PREVer propuestas
PEDVer pedidos
ALBVer albaranes
FACVer facturas
ADMAdministrador de clientes
ANUVer stocks anulados
ℹ️ Permiso ADM
El permiso ADM (Administrador de clientes) permite al usuario seleccionar el cliente al enviar propuestas y ver documentos (pedidos, albaranes, facturas) de varios clientes asignados a su código comercial.

Acceso al Sistema

Es la página de entrada al sistema. Presenta un diseño de dos paneles: el lateral izquierdo muestra el logo de la empresa y el panel derecho contiene el formulario de acceso.

ContraseñaCampo contraseña con botón para mostrar u ocultar el texto introducido (icono de ojo).

Acciones disponibles

🔑
Iniciar sesión Pulsar el botón de acceso o presionar Enter.
🔒
¿Olvidaste tu contraseña? Enlace que despliega un formulario inline para introducir el email. El sistema envía un email con un enlace de recuperación válido durante 1 hora.
✉️

⚠️ Atención

Cambio de contraseña obligatorio

Si la cuenta tiene marcado el flag "debe cambiar contraseña" (por ejemplo, en cuentas creadas por el administrador), el sistema muestra un modal inmediatamente después del inicio de sesión exitoso.

Contraseña nuevaMínimo 8 caracteres, debe contener mayúsculas, minúsculas, un número y un carácter especial.

  • 📋 Ver Todos: carga el catálogo completo sin filtros.
  • 🗑️ Limpiar: resetea todos los filtros al estado inicial.
  • 🎙️ Búsqueda por voz (opcional): reconoce formato, calidad y descripción mediante voz.

Funcionalidades avanzadas del grid

↕️
Ordenación por columna Clic en el encabezado de cualquier columna para ordenar de forma ascendente o descendente.
▼
Filtros de columna avanzados Clic en el icono de embudo de cada columna. Se abre un popup con dos pestañas: Valores (checkboxes de valores únicos) y Condición (operadores: contiene, igual, empieza por, termina en, etc.).
🏷️
Chips de filtros activos Los filtros de columna aplicados se muestran como etiquetas bajo la barra de filtros. Clic en la X de cada chip para eliminar ese filtro.
⟺
Reordenar columnas Arrastrar los encabezados para cambiar el orden de las columnas. El orden se guarda automáticamente.
↔️
Redimensionar columnas Arrastrar el borde derecho de cualquier columna para ajustar su anchura. Las anchuras se guardan automáticamente.
📄
Paginación configurable La cantidad de filas por página es configurable por el administrador desde los parámetros del sistema.

Modal de detalle del artículo

Al pulsar el botón Ver (👁️) o hacer clic en una fila, se abre el modal de detalle con toda la información del artículo:

  • Galería de imágenes: miniaturas ampliables. Clic en la imagen para verla a pantalla completa.
  • Badge de existencias: indicador visual del nivel de stock.
  • Ficha técnica PDF: botón de descarga (solo visible si existe ficha para ese artículo).
  • Datos de empaquetado: unidades por caja, cajas por pallet, peso por caja, peso por pallet.
  • Datos del artículo: código, EAN13, descripción, formato, modelo, color, calidad, tono, calibre, pallet, caja, existencias y precio (si permiso PRO).

Botones del modal de detalle

  • 🛒 Carrito: abre el modal de cantidad para añadir al carrito.
  • ❤️ Favorito: marca/desmarca el artículo como favorito.
  • 💬 Consulta: abre formulario para enviar consulta por email al equipo comercial.
  • 📱 WhatsApp: abre WhatsApp Web con mensaje prellenado con los datos del artículo.
  • ✖️ Cerrar: cierra el modal (también con clic fuera del modal o tecla Escape).

Stocks Anulados

Muestra artículos descatalogados que aún tienen existencias disponibles en almacén.

⚠️ Sección restringida
Esta sección solo es visible para usuarios con el permiso ANU activado por el administrador.

La estructura y funcionalidades son idénticas a la página principal de Stocks, con las siguientes diferencias:

  • Se muestra una banda informativa naranja en la parte superior indicando que son artículos anulados.
  • No dispone de carrito. Los artículos anulados no pueden ser incluidos en propuestas.
  • Mismo sistema de filtros, grid, detalle e imágenes que la página de Stocks.

Búsqueda Mágica

Funcionalidad de búsqueda visual por imagen usando tecnología de similitud (CBIR — Content-Based Image Retrieval). Permite encontrar productos similares a una imagen de referencia.

ℹ️ Requisito
Esta sección solo es visible si el administrador ha activado el parámetro VISIBLE_BUSQUEDA_MAGICA.

Cómo usar la búsqueda por imagen

  1. Arrastra una imagen directamente al área de carga, o haz clic para seleccionar un archivo.
  2. Formatos aceptados: JPG, PNG, WEBP. Tamaño máximo: 10 MB.
  3. El sistema analiza la imagen y devuelve productos visualmente similares.
  4. Cada resultado muestra el artículo con su porcentaje de similitud.
💡 Consejo
Para obtener mejores resultados, utiliza imágenes con buena iluminación, fondo neutro y que muestren claramente la textura o patrón del producto cerámico.

Mis Clientes

Muestra la lista de clientes asignados al código comercial del usuario en el ERP.

🔒 Permiso requerido
Esta sección solo es visible para usuarios con el permiso ADM (Administrador de clientes) activado por el administrador.

Con permiso ADM, el usuario también puede:

  • Seleccionar el cliente destinatario al enviar propuestas.
  • Ver pedidos, albaranes y facturas de todos sus clientes asignados (no solo uno).
  • Filtrar documentos por cliente en las páginas Mis Pedidos, Mis Albaranes y Mis Facturas.

Vista Almacén

🔒 Solo administradores
Requiere rol administrador o superusuario.

Visualización 3D interactiva del almacén construida con la librería Three.js. Permite explorar visualmente el estado del stock por ubicación física.

Funcionalidades

  • Selectores: elegir almacén y zona a visualizar.
  • Colorización: las celdas del almacén se colorean según su nivel de stock (verde = lleno, amarillo = medio, rojo = bajo, gris = vacío).
  • Modo paseo: navegar por el almacén en primera persona usando las teclas W, A, S, D.
  • Clic en celda: muestra información del artículo almacenado en esa ubicación.

Estadísticas mostradas

  • Número de zonas
  • Total de ubicaciones
  • Número de artículos distintos
  • Existencias totales

Informe Almacén

🔒 Solo administradores
Requiere rol administrador o superusuario.

Genera informes estadísticos del estado del almacén. Los informes son descargables e imprimibles directamente desde el navegador.

Incluye métricas como ocupación por zona, rotación de artículos, artículos sin movimiento y comparativas temporales.

Configuración Email

🔒 Solo administradores
Requiere rol administrador o superusuario.

Gestión de las configuraciones SMTP para el envío de emails del sistema (propuestas, verificación de cuentas, recuperación de contraseña, etc.).

Tipos de autenticación soportados

TipoDescripciónUso típico
BasicUsuario y contraseña SMTP estándar.Gmail, servidores SMTP propios.
OAuth2Autenticación mediante Azure Active Directory.Office 365 / Microsoft 365.

Acciones disponibles

  • Crear configuración: añadir nueva cuenta de envío (nombre, servidor SMTP, puerto, email remitente, destinatario).
  • Activar: marcar una configuración como activa (solo puede haber una activa por empresa).
  • Editar: modificar los datos de una configuración existente.
  • Probar conexión: botón para verificar que los datos SMTP son correctos antes de guardar.
💡 Consejo
Utiliza siempre el botón Probar conexión antes de activar una configuración para asegurarte de que el envío de emails funciona correctamente.

API Keys

🔒 Solo administradores
Requiere rol administrador o superusuario.

Gestión de claves de API para integraciones externas con el sistema (ERP, PowerBuilder, scripts de automatización, etc.).

Funcionamiento

  • Cada usuario puede generar sus propias API Keys.
  • Al crear una clave, el valor completo se muestra una única vez. No es posible recuperarlo después.
  • Las claves pueden ser desactivadas temporalmente sin eliminarlas.
  • Las claves pueden ser eliminadas permanentemente.

Uso de la API Key

La clave puede enviarse de dos formas en las peticiones a la API:

  • Header HTTP: X-API-Key: tu-clave-aqui
  • Query parameter: ?apikey=tu-clave-aqui
⚠️ Seguridad
Guarda la API Key en un lugar seguro justo después de crearla. Si la pierdes, deberás eliminarla y generar una nueva.
